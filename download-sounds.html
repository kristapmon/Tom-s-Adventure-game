Tom's Adventure - Sound Download Helper

Instructions

  1. For each sound below, click the "Create Sound" button to generate an audio file
  2. After hearing the sound, click "Download" to save it to your computer
  3. Save the file to your game's /sounds folder with the specified filename
  4. Repeat for all sounds required by the game
